# Paradise Nursery Shopping Application

Paradise Nursery is an online e-commerce plant shop built with React, Redux Toolkit, and Vite.

## Features
- **Landing Page**: Welcome banner, company mission, background styling, and a "Get Started" button.
- **Product Listing**: 3 distinct categories with at least 6 houseplants per category, complete with thumbnails, names, descriptions, and prices.
- **Dynamic Cart**: Redux-powered state tracking, real-time item counter in the navigation bar, quantity adjustment, and subtotal/total calculations.
- **Interactive Navigation**: Seamless switching between the landing view, plant catalog, and shopping cart.

## Tech Stack
- React
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- CSS3
